# TUPPEN Support

TUPPEN is an open-source iOS adaptation of the traditional German card game Tuppen.

## Help

If you encounter a problem with the app, please include:

- your iPhone model
- your iOS version
- the TUPPEN app version
- a short description of what happened

## Contact

For bug reports and technical issues, you can use the TUPPEN GitHub repository:

https://github.com/DerFerdi/Tuppen/issues

For other enquiries:

**Email:** ferdinand.majcherek@web.de

## Privacy

TUPPEN does not collect personal data, use advertising, analytics, or tracking.

See the full privacy policy for details.
